Last.fm account

  1. Sign in to Last.fm. If you already registered an app, open My Last.fm API accounts and select that app. Otherwise, register a Last.fm API application.
  2. Copy the API key and Shared secret from the same API application page. The shared secret is not your Last.fm password and does not appear in your regular profile settings.
  3. Paste both below and click Connect Last.fm. That saves the credentials and opens Last.fm for approval. Then return here and click Finish connecting.

Blank fields leave saved credentials unchanged.
